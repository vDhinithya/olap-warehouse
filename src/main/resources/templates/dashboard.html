1. 3D OLAP Conceptual Cube

The system models a 3-Dimensional analytical cube (ROLAP).
• X-Axis: Geography (City)
• Y-Axis: Category (Cuisine)
• Z-Axis: Service (Delivery Status)
Measures: Cost, Votes & Ratings.

2. Slice & Dice Operations

Using the dashboard controls to filter by 'City' performs a true SLICE on the 3D cube, isolating a 2D plane of Cuisines and Delivery metrics for that specific geography.

3. Roll-up & Drill-down

Default charts display global ROLL-UP aggregations. Applying filters executes a DRILL-DOWN, transitioning from macro geographical trends to micro restaurant-level facts.
